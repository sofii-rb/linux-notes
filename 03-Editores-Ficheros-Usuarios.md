## Editores de Texto

Trabajar con la creación y modificación de scripts

- Script= Fichero de texto, contiene comandos de Unix o Linux, para que sean ejecutados en una Shell.
  Interprete de comandos que realiza lectura

## Tipos de Usuario

En Linux hay 3 tipos de usuario:
- Usuario Root o administrador
- Usuario normal o de trabajo
- Usuarios especiales o de sistema

Los usuarios tienen un directorio propio llamado home al que solo ellos tienen acceso.
Se les asigna una Shell para el acceso
