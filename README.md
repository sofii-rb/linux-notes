# linux-notes
Mi documentación y prácticas de Linux.

Este repositorio forma parte de mi proceso de aprendizaje como estudiante de Ingeniería de Sistemas. Aquí documento los conceptos que aprendo, ejemplos, ejercicios y comandos que utilizo durante mi estudio.

## OBJETIVOS

- Aprender Linux desde cero.
- Comprender el funcionamiento de la terminal.
- Familiarizarme con la administración de archivos y permisos.
- Aprender Bash.
- Prepararme para Docker, Azure y administración de servidores.
