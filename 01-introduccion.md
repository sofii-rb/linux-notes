# INTRO / INSTALACIÓN

## ¿Qué es Linux?

Linux es un sistema operativo de código abierto basado en Unix.

## ¿Por qué aprender Linux?

- Es el sistema operativo más utilizado en servidores.
- Es fundamental para DevOps y Backend.
- Docker y Kubernetes funcionan principalmente sobre Linux.
- Azure, AWS y Google Cloud utilizan servidores Linux.


Linux es el "idioma" que hablan la mayoría de los servidores del mundo. Si quiero trabajar con backend, la nube o DevOps, necesito aprender.
