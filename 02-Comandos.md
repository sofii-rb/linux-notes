## Interprete de Comandos

Shell - CLI Interpreter
> sh

Reconoce lo que el usuario escriba en la terminal, reconoce los comandos.

##
  
df -h    ---> configuración unidades de almacenamiento

Existen los comandos con opciones y argumentos y los comandos sin opciones y argumentos.

date  ---> fecha y hora

Ctrl + C   ---> cancelar un comando

clear    ---> Limpiar terminal

ls   ---> Ubicación en el sistema


cd (nombre de carpeta)  ---> Entrar a una carpeta

cd . .  ---> Volver a la ubicación anterior


su -  ---> Acceder al usuario root = control total del sistema op

free -m  ---> Memoria disponible de nuestro sistema op

top  ---> Procesos y servicios activos en nuestro sistema op

htop  ---> Más info sobre los comandos activos

apt  ---> gestor de descargas de linux
apt search (nombre paquete)  --> opciones de descarga
apt install (nombre del paquete)  --> Instalar
